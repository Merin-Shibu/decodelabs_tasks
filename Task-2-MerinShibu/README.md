# Data Classification Using AI

## Project Overview

This project demonstrates a basic supervised machine learning classification model using the Iris dataset.

The model is trained using the K-Nearest Neighbors (KNN) algorithm to classify Iris flowers into three different species:

- Setosa
- Versicolor
- Virginica

## Objective

The objective of this project is to understand the basic machine learning classification workflow:

1. Load and understand a dataset
2. Split the dataset into training and testing sets
3. Scale the features
4. Train a classification model
5. Make predictions
6. Evaluate the model performance

## Dataset

The project uses the built-in Iris dataset provided by Scikit-learn.

The dataset contains:

- 150 samples
- 4 features
- 3 target classes

The four features are measurements of the Iris flowers.

## Technologies Used
