# DecodeLabs Internship Tasks

This repository contains the Artificial Intelligence projects completed as part of the DecodeLabs Internship Program.

## Projects

### Task 1 — Rule-Based AI Chatbot

A simple rule-based chatbot built using Python and predefined responses.

**Technologies:**
- Python
- If-else conditions
- Dictionaries
- Control flow

### Task 2 — Data Classification Using AI

An AI-based classification project using the Iris dataset and the K-Nearest Neighbors (KNN) algorithm.

**Technologies:**
- Python
- Pandas
- Scikit-learn
- KNN
- Feature Scaling

**Result:**
- Accuracy: 100%
- F1 Score: 1.00

### Task 3 — Tech Stack Recommender

A content-based recommendation system that recommends career paths based on the user's technical skills.

**Technologies:**
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity

### Task 4 — Image Text Recognition

A basic OCR system that extracts text from an image using Tesseract OCR.

**Technologies:**
- Python
- OpenCV
- Pytesseract
- Tesseract OCR

**Result:**
- Average OCR Confidence: 95.17%
- Recognition Confidence: PASS
